## Current API

- GET /health
- GET /api/runtime
- GET /api/agents
- POST /api/cases/validate
- POST /api/agents/{agent_id}/assess

The one-agent endpoint is a prototype. It validates output shape and enforces education-only safety fields. Evidence claims remain disabled because the evidence retrieval subsystem is not implemented. The case-validation endpoint checks request structure only; it does not validate clinical correctness or recommend treatment.

## Local folder layout

The self-hosted runner and local model store remain at the project root. GitHub synchronizes source code into the separate Source subfolder, without deleting or overwriting the runner or AI_Models directories.

Run the local application from Source with:

    powershell -ExecutionPolicy Bypass -File .\scripts\start-local.ps1

The launcher prepares the Python environment, checks/starts Ollama if needed, starts FastAPI and Vite on localhost, and opens the dashboard.
